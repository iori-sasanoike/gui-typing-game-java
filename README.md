# 徹夜レポートタイピングゲーム

大学のレポート提出締め切りに追われる状況を体験できる、Java Swingベースのタイピングゲームです。画面上部から落ちてくるお題（ひらがな）をローマ字で入力して消去し、朝7時（ゲーム内時間で7時間）になる前にレポート完成を目指します。

---

## 概要

- **ゲームテーマ**: 徹夜でのレポート作成
- **勝利条件**: 制限時間内（朝7時まで）にお題を消し続け、目標文字数（10,000文字）を達成すること
- **敗北条件**: 画面下に通常単語が到達するか、ゲーム内時間が朝7時（ゲーム内時間420分）に達すること
- **主な特徴**:
  - ローマ字入力によるひらがな自動変換処理
  - 通常単語とエナジー単語（高得点・スルー可能）の落下
  - 難易度選択機能（EASY, NORMAL, HARD）
  - ESCキーによる「ボス（教授・親など）が来た時」用の画面切り替え（緊急回避・ルール表示）機能

---

## 動作環境・必要条件

- Java SE 8 以上（Java 11 / 17 / 21 等）
- Swing / AWT ライブラリ（Java標準）
- JUnit 5（テスト実行時）
